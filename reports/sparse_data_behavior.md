# Sparse data behaviour

| Local technique n | Behaviour |
|-------------------|-----------|
| 0 | Prior-dominated; wide SD; max evidence LEVEL_2 |
| 1–2 | Partial empirical; no spline; large residual |
| ≥3 | Penalized spline on log-ratio allowed |

Missing ordinary baseline → NA (`missing_baseline` / `missing_baseline_or_pitch`). No silent pooling across instruments.
